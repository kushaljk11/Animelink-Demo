This section covers features that could be added after the main FYP version is completed, especially after further research, brainstorming, testing, and supervisor feedback.

Possible future enhancements include:

- **Mobile Application:** Develop dedicated Android and iOS apps for easier access and field use.
- **Advanced AI Breed Recognition:** Improve the breed prediction model using a larger and more locally relevant dataset.
- **Smart Duplicate Stray Detection:** Use image similarity, markings, location, and historical records to improve stray matching.
- **Advanced Rabies Risk Prediction:** Apply machine learning to historical incident, location, and seasonal data to identify possible future risk patterns.
- **Government System Integration:** Connect with municipal, veterinary, or public-health systems if APIs and permissions become available.
- **Vet Appointment Booking:** Allow pet owners to book vaccination or consultation appointments directly with registered clinics.
- **Expanded Medical Records:** Add treatment history, prescriptions, allergies, deworming, and other animal-health records.
- **Microchip Integration:** Link pet profiles with microchip numbers where available.
- **Advanced Lost-Pet Alerts:** Send location-based alerts to nearby users when a pet is reported missing.
- **Push Notifications:** Add browser or mobile push notifications for reminders and emergency alerts.
- **Offline Support:** Allow selected features to work with limited connectivity and synchronize when internet access returns.
- **Advanced Dashboards:** Provide more detailed municipal statistics, trends, comparisons, and reporting tools.
- **Public Awareness Module:** Include educational content about rabies prevention, responsible pet ownership, vaccination, and safe response to animal bites.
- **Additional Languages:** Expand beyond Nepali and English if required.
- **Inter-Municipality Support:** Allow multiple municipalities to use the same platform with separate administrative access.
- **Research Data Export:** Provide anonymized datasets for approved academic or public-health research.

### Future Scope Principle

The current system is designed with a defined FYP scope, but it should remain flexible enough to support additional useful features identified through **research, brainstorming, user feedback, technical evaluation, and supervisor consultation**.
